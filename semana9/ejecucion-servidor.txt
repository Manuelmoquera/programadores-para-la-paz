Al ejecutar node server.js se inicia el servidor Node.js.

En la terminal aparece el mensaje:
"Servidor ejecutándose en puerto 3000".

Al visitar la ruta /estado se muestra un objeto JSON con información del estado del servidor y del servicio API comunitaria.

Respuesta obtenida:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}

Repositorio:
Un repositorio es un espacio donde se almacenan los archivos y cambios de un proyecto. Permite organizar el trabajo y mantener un historial de modificaciones.

Commit:
Un commit es un registro de cambios realizados en un proyecto. Cada commit guarda una versión específica del trabajo junto con un mensaje descriptivo.

Push:
Push es el comando que permite enviar los cambios del repositorio local hacia GitHub. Esto ayuda a compartir y respaldar el proyecto.

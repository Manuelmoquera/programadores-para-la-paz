El login es el proceso mediante el cual un usuario se identifica en una aplicación utilizando sus credenciales. Gracias a la autenticación, el sistema puede verificar quién accede y qué permisos tiene. Algunas rutas deben estar protegidas porque permiten realizar acciones importantes o acceder a información privada. Solo los usuarios autorizados deben ingresar a estas funciones. No se deben exponer públicamente contraseñas, documentos de identidad, números telefónicos, direcciones, tokens, claves de API ni otros datos sensibles. De esta manera se protege la privacidad y la seguridad de la comunidad.
